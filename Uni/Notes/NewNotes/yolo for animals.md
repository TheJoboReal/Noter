#### Definition
Running YOLO on a raspberry pi for detecting the location of rhinos. We are using this [guide](https://core-electronics.com.au/guides/getting-started-with-yolo-object-and-animal-recognition-on-the-raspberry-pi/) so far.


### Hardware
We need:
- Pi 5 4gb or 8gb.
- pi cam v3.
- Active cooler for pi(maybe some passive air-cooling).
