#### Definition
Setting up an ESP8266MOD on arduino-cli using lazyvim:
- Board: Generic ESP8266 Module.
- LED-PIN: GPIO2.
- Upload speed: 115200.
- CPU Frequency: 80Mhz or 160MHz.
- Crystal Frequency: 26Mhz or 40MHz.
- Flash Size: 4MB (FS:2MB OTA:~1019KB).
- Flash Mode: QIO.
- Flash Frequency: 40MHz.
